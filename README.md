# Student Task Tracker

A simple web application that helps students organize their academic tasks, assignments, projects, and deadlines.

## Project Overview

The Student Task Tracker was developed as part of the Git & GitHub Team Workflow Challenge. The project demonstrates collaborative software development using HTML, CSS, JavaScript, Git, and GitHub.

## Features

- Add tasks with a category, due date, and priority.
- Mark tasks as completed or pending.
- Delete tasks.
- Filter tasks by all, pending, and completed status.
- View total, pending, and completed task counters.
- Save tasks in the browser using localStorage.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Project Files

- `index.html` — Defines the structure and content of the application.
- `styles.css` — Controls the layout, colors, and responsive design.
- `script.js` — Handles task management and browser storage.
- `README.md` — Documents the project, features, team contributions, and collaboration workflow.

## Team Contributions

- **Member 1 — Team Leader:** Initialized the repository, prepared the starter code, documented the project, coordinated collaboration, reviewed pull requests, and tested the final application.
- **Member 2 — HTML Designer:** Completed the main HTML interface, including the task form, statistics, filters, and task list.
- **Member 3 — CSS Designer and JavaScript Developer:** Completed the remaining styling, responsive design, task-management functionality, filtering, and statistics.

## How to Run the Project

1. Clone or download the repository.
2. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

## Collaboration Workflow

The team uses one shared GitHub repository. Each member works on a separate branch, makes meaningful commits, pushes their changes, and submits a pull request for review. The Team Leader reviews and merges approved pull requests into the `main` branch.
